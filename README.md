# Cremitas

Base inicial de una pagina de ventas y presentacion de productos construida con Vite y React.

## Pantallas consideradas

- Presentacion principal de la marca y tipos de productos.
- Listado de productos con filtro por categoria.
- Seccion con tecnologias elegidas para esta etapa.

## Stack definido

- Vite para el entorno de desarrollo.
- React para crear componentes y escalar la interfaz.
- CSS para el diseno responsivo y la identidad visual.

## Proxima fase sugerida

- Integrar carrito y pedidos.
- Conectar backend con Firebase o Supabase.
- Agregar pagos con Mercado Pago.

## Como ejecutar

1. Instalar dependencias con `npm install`.
2. Levantar el proyecto con `npm run dev`.
